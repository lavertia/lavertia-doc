## Compose once in PHP. Render with any Inertia frontend.

<CardGrid>
  <Card title="Component-first" icon="puzzle">
    Place tables, forms, actions and infolists anywhere in your application—not only inside a Resource or a Panel.
  </Card>
  <Card title="Three frontends" icon="rocket">
    One PHP component tree can be rendered by Vue 3, React 19 or Svelte 5 through an Inertia adapter.
  </Card>
  <Card title="Laravel native" icon="open-book">
    Reuse policies, Eloquent, middleware, validation and authentication instead of reinventing your backend.
  </Card>
</CardGrid>
