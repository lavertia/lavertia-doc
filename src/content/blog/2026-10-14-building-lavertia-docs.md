Lavertia now has a dedicated documentation codebase in [lavertia/lavertia-doc](https://github.com/lavertia/lavertia-doc). The website is built to live on GitHub Pages, with **documentation pages, a development journal and a reviewed plugin directory**.

## Why a separate site?

The framework spans multiple repositories. A single README cannot track package boundaries, React/Vue/Svelte differences, authentication patterns and feature availability without becoming hard to navigate.

This site aims to provide:

- Practical installation examples using the current experimental Composer path repositories.
- Honest availability labels for shipped prototypes, draft Pull Requests and planned work.
- Guides for Eloquent query scoping, authorization and safe Inertia serialization.
- A lightweight editorial process where blog posts and plugins are reviewed through GitHub PRs.

## Current limitations

This is the **first website iteration**, not a Lavertia stable-release announcement. The current prototype requires further full-stack testing and package extraction before production adoption.

You can contribute by editing a guide or submitting an idea through the [documentation repository](https://github.com/lavertia/lavertia-doc).
